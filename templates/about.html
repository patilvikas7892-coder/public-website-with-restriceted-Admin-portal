Assignment 19 Tasks Checklist

  • Configure Security Groups:

    Defined stateful ingress/egress rules separating public web traffic from admin ports.

  • Restrict SSH to Administrator IP:

    Port 22 restricted exclusively to College IP (203.0.113.195/32).

  • Allow HTTPS Only:

    Port 80 auto-redirects to Port 443 with TLS 1.3 encryption and HSTS headers.

  • Store Uploaded Files in Object Storage:

    Decoupled storage in S3 bucket with public-assets and admin-docs prefixes.
